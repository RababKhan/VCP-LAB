#======== string options by option 'additional' ================
Additional useful options of full feature app can be used with string option 'additional'.
All available options of full feature app and vvencapp can be used in 'additional'.
Options are assigned by '(long)optionname=value'. Concatenate options with ':'
For instanse set hdr10 bt2020 mode (corresponds to option '--hdr pq_2020')
vvencapp  --additional ColourPrimaries=bt2020:TransferCharacteristics=smpte2084:MatrixCoefficients=bt2020nc
'additional' options are always parsed after all other options have been parsed!
Overview of usefull additional options:
